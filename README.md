# Indian Wok website

The new website for Indian Wok, Sophia and Ian Chung's Indian-Chinese restaurant in Burnaby. It's built with Next.js as a static export, for GitHub Pages at indianwok.ca.

**All project documentation lives in Kenneth's Second Brain vault, not here.** That includes setup, how to run and build, how to publish, requirements and decisions. Find it in the note `20 Areas/Home & Life Admin/Indian Wok.md`, in the *Setup & developer info* section.

Quick commands: `npm install` · `npm start` (builds, then serves the finished site at http://localhost:4000) · `npm run dev` (live-reload preview at http://localhost:3000) · `npm run build` (writes the site to `out/`).
