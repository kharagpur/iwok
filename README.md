# Indian Wok website

The new website for Indian Wok, an Indian-Chinese restaurant in Burnaby. It's built with Next.js as a static export, for GitHub Pages at indianwok.ca.

**All project documentation lives in the project notes, not here.** That includes setup, how to run and build, how to publish, requirements and decisions. Find it in `10 Projects/Indian Wok Website Redesign/Indian Wok Website Redesign.md`, in the *Setup & developer info* section.

Quick commands: `npm install` · `npm start` (builds, then serves the finished site at http://localhost:4000) · `npm run dev` (live-reload preview at http://localhost:3000) · `npm run build` (writes the site to `out/`).
